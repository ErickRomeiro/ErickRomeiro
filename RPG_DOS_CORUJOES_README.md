## 🚀 Rodando localmente

Requisitos: [Node 18+, npm/pnpm/yarn, banco X se aplicável]

```bash
# Clone o repositório
git clone https://github.com/ErickRomeiro/rpg-dos-corujoes.git
cd rpg-dos-corujoes

# Instale as dependências
npm install

# Configure variáveis de ambiente
cp .env.example .env
# Preencha .env com suas credenciais

# Rode em modo de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## 📖 Origem

Nasceu para o meu grupo de RPG de mesa — os Corujões. A gente jogava sistemas diferentes e o vai-e-vem entre PDFs, planilhas do Google e cadernos manuscritos ficou insustentável. Este projeto é a solução prática pra isso, construída em cima do problema real.
